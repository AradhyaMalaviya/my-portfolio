## 📌 Executive Engineering Summary

I am a **Full-Stack Software Engineer & AI/ML Systems Builder** focused on shipping resilient, high-throughput applications and production machine learning pipelines. My engineering practice bridges **applied artificial intelligence research** (Deep Reinforcement Learning, computer vision, multi-variate forecasting, LLMs) and **modern full-stack software architecture** (React 19, TypeScript, asynchronous FastAPI microservices, and containerized cloud deployments).

I maintain end-to-end technical ownership across my work — spanning dataset curation, feature engineering, mathematical optimization, RESTful API design, database modeling, responsive UI/UX engineering, and continuous deployment.

### 🚀 Core Competencies

- 🤖 **Applied AI & ML Systems:** Production inference microservices, Deep Q-Networks (DQN), XGBoost/LightGBM ensembles, computer vision (ALPR/OCR), and GenAI reasoning layers.
- 💻 **Modern Full-Stack SaaS:** Component-driven web apps with React 19, TypeScript, Next.js, SvelteKit, and Tailwind CSS engineered for sub-second page loads.
- ⚙️ **High-Performance Backends:** Low-latency REST & WebSocket microservices using FastAPI, Python, Node.js, and Express with JWT authentication and connection pooling.
- 🗄️ **Databases & Data Engineering:** Schema design, spatial queries, and caching with PostgreSQL, PostGIS, MongoDB, Redis, and Supabase.
- ☁️ **DevOps & Cloud Deployment:** Automated CI/CD pipelines, Docker containerization, edge deployments on Cloudflare Pages & Vercel, and Prometheus observability.
